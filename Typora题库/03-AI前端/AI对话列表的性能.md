# 题 5：AI 对话列表一卡一卡，你怎么查、怎么优？

- 如何定位是 markdown、高亮，还是列表重渲染？
- 虚拟列表和「贴底滚动」怎么同时做？

## 参考答

**常见原因**
- 每次 chunk 更新导致整列表重渲染
- Markdown + 语法高亮同步跑在主线程
- 自动滚到底每次 layout/reflow
- 大图/多代码块累积在 DOM

**排查**
- React Profiler：看哪个组件高频 commit
- Performance：长任务是否在 markdown/highlight
- 关掉高亮/markdown 对比是否流畅

**优化组合**
- 消息项 `memo` + 稳定回调；streaming 中降级为纯文本
- 虚拟列表；贴底用「用户是否在底部」判断，避免抢滚动
- 代码高亮异步/空闲时再做
- 图片懒加载与尺寸占位

**业务例子**：一次回答出超长代码，打字机还在跑同时 Prism 同步高亮——应等结束或对当前块节流高亮。
