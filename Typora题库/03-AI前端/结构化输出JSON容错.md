# 题 16：结构化输出（JSON mode）前端解析容错与降级？

## 面试官可能怎么问

- 模型声称输出 JSON 但坏了怎么办？
- 如何降级成纯文本？

## 先自己答（90 秒）

## 参考答

**目标**：后端/模型约定 JSON schema（题目列表、matches、翻译结果）；前端要能扛「几乎是 JSON」。

**容错顺序**
1. `JSON.parse` 全量
2. 提取首个代码块 ` ```json `
3. 截取第一个 `{`/`[` 到最后一个 `}`/`]` 再 parse
4. 仍失败 → **降级纯文本展示**，并标记 `parseError`；提供「重试/重新生成」
5. 不要对失败结果「脑补字段」写成假成功

**UI**
- 成功：按 schema 渲染表格/卡片
- 失败：原文 + 警告条「未通过结构校验」

**业务例子**：质检 Agent 应产出错误数组；parse 失败时展示原始报告比空白更好。

## 可能追问

- 用 JSON mode 还要不要容错？→ 要；截断/超时仍会坏。
- 流式 JSON？→ 未完成前不 parse；或用增量解析器。
