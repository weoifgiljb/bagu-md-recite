# 题 1：两数之和（LeetCode 1）

## 面试官可能怎么问
- 给定数组和 target，返回两个数的下标？
- 能不能少于 O(n²)？
- 有多个解怎么办？

## 口述结构（90 秒）
1. 题意：找两数之和等于 target，返回下标
2. 哈希表边扫边存：看 target-x 是否出现过
3. 一遍 O(n)，注意不能用同一个下标两次

## 参考答案

### 思路
用 Map 存「值 → 下标」。扫到 nums[i] 时，看 target-nums[i] 是否已在 Map；在则返回两个下标，否则把当前值放进 Map。这样保证只用一次遍历，且不会用到未来的元素当「已出现」。

### 复杂度
时间 O(n)，空间 O(n)

### 代码骨架（JavaScript）
```js
function twoSum(nums, target) {
  const map = new Map();
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (map.has(need)) return [map.get(need), i];
    map.set(nums[i], i);
  }
  return [];
}
```

### 边界与追问
- 题目保证恰好一组解时直接返回
- 若需所有解：找到后 continue，注意去重策略
- 排序+双指针会打乱下标，除非一起存 index
