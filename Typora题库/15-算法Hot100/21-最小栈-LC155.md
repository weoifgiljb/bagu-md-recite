# 题 21：最小栈（LeetCode 155）

## 面试官可能怎么问
- O(1) 取最小值的栈？
- 如何同步最小值？

## 口述结构（90 秒）
1. 辅栈存当前最小值
2. push 时压 min(x, 当前min)
3. pop 两个栈一起弹

## 参考答案

### 思路
主栈正常存值；minStack 在每次 push 时压入 `min(x, minStack.top())`（空则压 x）。getMin 读 minStack 栈顶。这样每个元素对应一个当时的全局最小。

### 复杂度
时间 O(1) 各操作，空间 O(n)

### 代码骨架（JavaScript）
```js
class MinStack {
  constructor() { this.st = []; this.mn = []; }
  push(x) {
    this.st.push(x);
    this.mn.push(this.mn.length ? Math.min(x, this.mn[this.mn.length - 1]) : x);
  }
  pop() { this.st.pop(); this.mn.pop(); }
  top() { return this.st[this.st.length - 1]; }
  getMin() { return this.mn[this.mn.length - 1]; }
}
```

### 边界与追问
- 差值法可省空间但实现易错
- 重复最小值要压多次
- 空栈调用题目一般保证合法
