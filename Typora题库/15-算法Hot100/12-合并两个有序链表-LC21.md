# 题 12：合并两个有序链表（LeetCode 21）

## 面试官可能怎么问
- 合并两个升序链表？
- 哑节点有什么用？

## 口述结构（90 秒）
1. 哑节点 + 尾指针
2. 每次接更小的头
3. 剩余一条直接接上

## 参考答案

### 思路
创建 dummy，tail=dummy。比较 list1/list2 值，小的接到 tail.next 并前进。最后把非空的那条接上，返回 dummy.next。

### 复杂度
时间 O(n+m)，空间 O(1)

### 代码骨架（JavaScript）
```js
function mergeTwoLists(list1, list2) {
  const dummy = { next: null };
  let tail = dummy;
  while (list1 && list2) {
    if (list1.val < list2.val) { tail.next = list1; list1 = list1.next; }
    else { tail.next = list2; list2 = list2.next; }
    tail = tail.next;
  }
  tail.next = list1 || list2;
  return dummy.next;
}
```

### 边界与追问
- 一条为空
- 有相等值时任意接
- 追问合并 K 条 → 优先队列 / 分治
