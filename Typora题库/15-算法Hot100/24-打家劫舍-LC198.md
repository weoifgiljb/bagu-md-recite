# 题 24：打家劫舍（LeetCode 198）

## 面试官可能怎么问
- 相邻房屋不能都偷，最大金额？
- 状态怎么定义？

## 口述结构（90 秒）
1. dp[i]=max(dp[i-1], dp[i-2]+nums[i])
2. 偷或不偷当前
3. 滚动两变量

## 参考答案

### 思路
对每间房：不偷则继承上一家最优；偷则等于上上家最优+当前。取 max。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function rob(nums) {
  let prev = 0, curr = 0;
  for (const x of nums) {
    const next = Math.max(curr, prev + x);
    prev = curr; curr = next;
  }
  return curr;
}
```
