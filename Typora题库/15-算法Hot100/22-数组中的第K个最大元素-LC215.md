# 题 22：数组中的第 K 个最大元素（LeetCode 215）

## 面试官可能怎么问
- 第 k 大（不是第 k 小）？
- 快选和堆怎么选？

## 口述结构（90 秒）
1. 快选：分区，pivot 落位即答案
2. 小顶堆维护 k 个最大
3. 面试讲清平均 O(n)

## 参考答案

### 思路
快速选择：随机 pivot 分区，目标下标是 n-k（第 k 大）。pivot 下标命中即返回；太右丢右边，太左丢左边。堆做法：大小为 k 的小顶堆，扫完堆顶即第 k 大。

### 复杂度
快选平均 O(n) 最坏 O(n²)；堆 O(n log k)

### 代码骨架（JavaScript）
```js
function findKthLargest(nums, k) {
  const target = nums.length - k;
  function partition(l, r) {
    const pivot = nums[r];
    let i = l;
    for (let j = l; j < r; j++) if (nums[j] <= pivot) {
      [nums[i], nums[j]] = [nums[j], nums[i]]; i++;
    }
    [nums[i], nums[r]] = [nums[r], nums[i]];
    return i;
  }
  let l = 0, r = nums.length - 1;
  while (true) {
    const p = partition(l, r);
    if (p === target) return nums[p];
    if (p < target) l = p + 1;
    else r = p - 1;
  }
}
```

### 边界与追问
- 有重复值
- k=1 / k=n
- JS 无现成堆可用排序偷懒但要主动提更优解
