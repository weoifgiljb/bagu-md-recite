# 题 25：最大子数组和（LeetCode 53）

## 面试官可能怎么问
- 连续子数组最大和？
- Kadane 怎么讲？

## 口述结构（90 秒）
1. 扫到 x：要么接在前一段后，要么自己开新段
2. cur=max(x, cur+x)
3. 维护全局 max

## 参考答案

### 思路
Kadane：当前最大子段和 cur；若 cur+x 还不如 x 本身，就从 x 重启。同时更新 ans。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function maxSubArray(nums) {
  let cur = nums[0], ans = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    ans = Math.max(ans, cur);
  }
  return ans;
}
```

### 边界与追问
- 全负数：答案是最大的那个负数
- 追问返回下标区间
- 分治解法了解即可
