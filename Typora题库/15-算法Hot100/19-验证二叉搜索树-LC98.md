# 题 19：验证二叉搜索树（LeetCode 98）

## 面试官可能怎么问
- 如何判断一棵树是 BST？
- 为什么只比和父节点不够？

## 口述结构（90 秒）
1. 每个节点有值域 (low, high)
2. 中序应严格递增
3. 递归传上下界

## 参考答案

### 思路
错误做法：只判断左<根<右。正确：左子树都 < 根，右子树都 > 根。递归带 (min,max) 边界；或中序遍历看是否严格递增。注意用 -Infinity/Infinity，且不能用等于。

### 复杂度
时间 O(n)，空间 O(h)

### 代码骨架（JavaScript）
```js
function isValidBST(root) {
  function ok(node, lo, hi) {
    if (!node) return true;
    if (node.val <= lo || node.val >= hi) return false;
    return ok(node.left, lo, node.val) && ok(node.right, node.val, hi);
  }
  return ok(root, -Infinity, Infinity);
}
```

### 边界与追问
- 节点值等于边界要失败
- 单支长链
- 中序写法别忘 prev
