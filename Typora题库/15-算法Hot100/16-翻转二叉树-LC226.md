# 题 16：翻转二叉树（LeetCode 226）

## 面试官可能怎么问
- 左右子树整体交换？
- 层序也能做吗？

## 口述结构（90 秒）
1. 交换当前左右指针
2. 递归处理左右孩子
3. 或队列迭代交换

## 参考答案

### 思路
经典：`[root.left, root.right]=[root.right, root.left]` 后递归两边。面试可提这是前序/后序都可，只要每个节点交换一次。

### 复杂度
时间 O(n)，空间 O(h)

### 代码骨架（JavaScript）
```js
function invertTree(root) {
  if (!root) return null;
  [root.left, root.right] = [root.right, root.left];
  invertTree(root.left);
  invertTree(root.right);
  return root;
}
```

### 边界与追问
- 空树
- 不要和「镜像判断」搞混：翻转是改树，对称是判断
