# 题 9：找到字符串中所有字母异位词（LeetCode 438）

## 面试官可能怎么问
- 在 s 中找 p 的异位词子串起始下标？
- 固定窗口怎么滑？

## 口述结构（90 秒）
1. 窗口长度 = p.length
2. 维护 26 计数差或匹配数
3. 右进左出一个字符

## 参考答案

### 思路
先统计 p 的计数。在 s 上维护同样长度窗口的计数；也可用 `differ` 记录有多少字母计数不一致。每次窗口右移：加右边、减左边，differ 为 0 则记录起点。

### 复杂度
时间 O(n)，空间 O(1)（26 字母）

### 代码骨架（JavaScript）
```js
function findAnagrams(s, p) {
  if (s.length < p.length) return [];
  const need = Array(26).fill(0);
  const win = Array(26).fill(0);
  const A = 'a'.charCodeAt(0);
  for (const ch of p) need[ch.charCodeAt(0) - A]++;
  const res = [];
  const m = p.length;
  for (let i = 0; i < s.length; i++) {
    win[s.charCodeAt(i) - A]++;
    if (i >= m) win[s.charCodeAt(i - m) - A]--;
    if (i >= m - 1 && need.every((v, j) => v === win[j])) res.push(i - m + 1);
  }
  return res;
}
```

### 边界与追问
- p 比 s 长
- 只有小写时计数数组够用
- 和 LC49 异位词思想同源
