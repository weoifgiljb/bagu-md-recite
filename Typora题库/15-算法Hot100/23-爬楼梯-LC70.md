# 题 23：爬楼梯（LeetCode 70）

## 面试官可能怎么问
- 一次 1 或 2 阶，n 阶几种走法？
- 和斐波那契关系？

## 口述结构（90 秒）
1. dp[i]=dp[i-1]+dp[i-2]
2. 滚动变量省空间
3. 本质斐波那契

## 参考答案

### 思路
到第 i 阶只能从 i-1 或 i-2 来。边界 dp[1]=1,dp[2]=2。滚动 a,b 即可。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function climbStairs(n) {
  if (n <= 2) return n;
  let a = 1, b = 2;
  for (let i = 3; i <= n; i++) {
    const c = a + b; a = b; b = c;
  }
  return b;
}
```

### 边界与追问
- n=1
- 追问一次最多 k 阶 → 泛化转移
- 矩阵快速幂 O(log n) 加分
