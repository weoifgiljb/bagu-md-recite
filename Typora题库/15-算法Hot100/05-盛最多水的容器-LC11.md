# 题 5：盛最多水的容器（LeetCode 11）

## 面试官可能怎么问
- 两条竖线与 x 轴构成容器，最大面积？
- 为什么双指针从两端收？

## 口述结构（90 秒）
1. 面积 = min(h[l],h[r]) * (r-l)
2. 矮的那边内移才可能变大
3. O(n) 扫一遍

## 参考答案

### 思路
左右指针在两端。当前面积由短板决定；移动短板一侧，才有机会让 min 变高。移动长板只会让宽度变小且 min 不会变大。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function maxArea(height) {
  let l = 0, r = height.length - 1, best = 0;
  while (l < r) {
    best = Math.max(best, Math.min(height[l], height[r]) * (r - l));
    if (height[l] < height[r]) l++;
    else r--;
  }
  return best;
}
```

### 边界与追问
- n=2 的最小情况
- 等高时可任意移一侧
- 不要和「接雨水」LC42 混淆
