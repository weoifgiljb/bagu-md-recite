# 题 3：最长连续序列（LeetCode 128）

## 面试官可能怎么问
- 要求 O(n)，不能先整体排序怎么做？
- 为什么只从序列起点扩展？

## 口述结构（90 秒）
1. 放进 Set 去重
2. 只对「没有 x-1」的数当起点向后扩
3. 维护最长长度

## 参考答案

### 思路
先把所有数放进 Set。遍历每个 x，若 x-1 不在 Set，说明 x 是某段连续序列起点，然后 while 查 x+1、x+2… 计数。每个数最多被访问常数次，整体近似 O(n)。

### 复杂度
时间 O(n)，空间 O(n)

### 代码骨架（JavaScript）
```js
function longestConsecutive(nums) {
  const set = new Set(nums);
  let best = 0;
  for (const x of set) {
    if (set.has(x - 1)) continue;
    let y = x, len = 1;
    while (set.has(y + 1)) { y++; len++; }
    best = Math.max(best, len);
  }
  return best;
}
```

### 边界与追问
- 空数组返回 0
- 有重复时 Set 已处理
- 负数、跨 0 的连续一样适用
