# 题 7：接雨水（LeetCode 42）

## 面试官可能怎么问
- 柱状图能接多少水？
- 双指针和预处理左右最高哪个更常讲？

## 口述结构（90 秒）
1. 每个位置水量 = min(左最高,右最高)-height[i]
2. 双指针：哪侧最高更小就结算哪侧
3. 或两个数组预存 leftMax/rightMax

## 参考答案

### 思路
双指针版：l、r 从两端向中间。维护 leftMax、rightMax。若 height[l]<height[r]，则 l 侧瓶颈在 leftMax，可结算 l 再 l++；否则结算 r。直觉：较矮一侧的上界已被对侧更高柱「兜住」。

### 复杂度
时间 O(n)，空间 O(1)（双指针）

### 代码骨架（JavaScript）
```js
function trap(height) {
  let l = 0, r = height.length - 1;
  let leftMax = 0, rightMax = 0, ans = 0;
  while (l < r) {
    if (height[l] < height[r]) {
      leftMax = Math.max(leftMax, height[l]);
      ans += leftMax - height[l];
      l++;
    } else {
      rightMax = Math.max(rightMax, height[r]);
      ans += rightMax - height[r];
      r--;
    }
  }
  return ans;
}
```
