# 题 10：反转链表（LeetCode 206）

## 面试官可能怎么问
- 反转单链表？
- 迭代和递归怎么讲？

## 口述结构（90 秒）
1. 迭代：pre、cur，切断再接
2. 保存 next，cur.next=pre，三人走一步
3. 递归：反转后面，再把后继指回来

## 参考答案

### 思路
迭代最稳：`pre=null, cur=head`。循环里 `next=cur.next; cur.next=pre; pre=cur; cur=next`。返回 pre。

### 复杂度
时间 O(n)，空间 O(1) 迭代 / O(n) 递归栈

### 代码骨架（JavaScript）
```js
function reverseList(head) {
  let pre = null, cur = head;
  while (cur) {
    const next = cur.next;
    cur.next = pre;
    pre = cur;
    cur = next;
  }
  return pre;
}
```
