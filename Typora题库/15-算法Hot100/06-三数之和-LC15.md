# 题 6：三数之和（LeetCode 15）

## 面试官可能怎么问
- 找所有和为 0 的不重复三元组？
- 如何去重？

## 口述结构（90 秒）
1. 先排序
2. 枚举 i，对剩余双指针找两数之和 = -nums[i]
3. 跳过重复的 i、L、R

## 参考答案

### 思路
排序后固定 i，L=i+1，R=n-1。和太大 R--，太小 L++，相等则记录并两边跳过相同值。i 也要跳过重复，避免重复三元组。

### 复杂度
时间 O(n²)，空间 O(1) 不计输出

### 代码骨架（JavaScript）
```js
function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const res = [];
  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) continue;
    let l = i + 1, r = nums.length - 1;
    while (l < r) {
      const s = nums[i] + nums[l] + nums[r];
      if (s === 0) {
        res.push([nums[i], nums[l], nums[r]]);
        while (l < r && nums[l] === nums[l + 1]) l++;
        while (l < r && nums[r] === nums[r - 1]) r--;
        l++; r--;
      } else if (s < 0) l++;
      else r--;
    }
  }
  return res;
}
```

### 边界与追问
- 全正/全负无解
- 多个 0：[0,0,0]
- 追问四数之和 → 再套一层枚举
