# 题 2：字母异位词分组（LeetCode 49）

## 面试官可能怎么问
- 如何把异位词分到同一组？
- 排序当 key 和计数当 key 差在哪？

## 口述结构（90 秒）
1. 异位词 = 字母计数相同
2. 用排序后的串或 26 维计数当哈希 key
3. Map 收集同 key 的原串

## 参考答案

### 思路
对每个字符串：要么 `sorted(s).join('')` 当 key，要么用长度 26 的计数数组转成如 `a1b2...` 的签名。同一签名丢进同一个数组。排序法写起来短；计数法在长串上常数更好。

### 复杂度
时间 O(n * k log k)（排序）或 O(n * k)（计数），空间 O(n * k)

### 代码骨架（JavaScript）
```js
function groupAnagrams(strs) {
  const map = new Map();
  for (const s of strs) {
    const key = [...s].sort().join('');
    if (!map.has(key)) map.set(key, []);
    map.get(key).push(s);
  }
  return [...map.values()];
}
```

### 边界与追问
- 空串也是一组
- Unicode 不只 26 字母时排序法更通用
- 追问：如何判断两个串是否异位词 → 同样签名
