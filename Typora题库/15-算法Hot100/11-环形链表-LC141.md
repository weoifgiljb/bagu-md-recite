# 题 11：环形链表（LeetCode 141）

## 面试官可能怎么问
- 判断是否有环？
- 快慢指针为什么能相遇？

## 口述结构（90 秒）
1. 慢走 1 快走 2
2. 有环则必相遇
3. 也可用 Set 存节点

## 参考答案

### 思路
Floyd：slow、fast 从 head 出发，fast 每次两步。若存在环，相对速度为 1，必在环内追上。无环则 fast 先到 null。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

### 边界与追问
- 追问环入口 → LC142 再走一次同步指针
- 环在开头
- 不要改节点 val 当标记（面试减分）
