# 题 4：移动零（LeetCode 283）

## 面试官可能怎么问
- 把 0 移到末尾且保持非零相对顺序？
- 能否原地 O(1) 空间？

## 口述结构（90 秒）
1. 快慢指针：慢指针写非零
2. 一遍交换或覆盖
3. 剩余位置补 0（若用覆盖）

## 参考答案

### 思路
维护写指针 `j`。遍历 i，遇到非零就与 j 交换（或赋给 nums[j] 后 j++）。这样非零按原序堆到前面，后面自然都是 0。

### 复杂度
时间 O(n)，空间 O(1)

### 代码骨架（JavaScript）
```js
function moveZeroes(nums) {
  let j = 0;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      [nums[j], nums[i]] = [nums[i], nums[j]];
      j++;
    }
  }
}
```

### 边界与追问
- 全是 0 / 没有 0
- 要求必须原地修改
- 追问：稳定吗？→ 相对顺序保持则稳定
