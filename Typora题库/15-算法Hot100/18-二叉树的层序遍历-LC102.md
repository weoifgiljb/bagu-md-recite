# 题 18：二叉树的层序遍历（LeetCode 102）

## 面试官可能怎么问
- 按层输出二维数组？
- 如何控制一层边界？

## 口述结构（90 秒）
1. 队列 BFS
2. 每层开始时记录 size
3. size 次出队并收集

## 参考答案

### 思路
队列放 root。while 队列非空：sz=queue.length，循环 sz 次出队，把 val 放进本层数组，左右孩子入队。本层数组 push 进答案。

### 复杂度
时间 O(n)，空间 O(n)

### 代码骨架（JavaScript）
```js
function levelOrder(root) {
  if (!root) return [];
  const res = [], q = [root];
  while (q.length) {
    const sz = q.length, level = [];
    for (let i = 0; i < sz; i++) {
      const node = q.shift();
      level.push(node.val);
      if (node.left) q.push(node.left);
      if (node.right) q.push(node.right);
    }
    res.push(level);
  }
  return res;
}
```

### 边界与追问
- shift 可换真队列避免 O(n²)
- 追问锯齿层序 → 隔层 reverse
- 右侧视图 → 每层最后一个
