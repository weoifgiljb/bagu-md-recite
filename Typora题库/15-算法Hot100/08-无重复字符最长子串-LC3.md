# 题 8：无重复字符的最长子串（LeetCode 3）

## 面试官可能怎么问
- 最长无重复字符子串长度？
- 滑动窗口怎么维护？

## 口述结构（90 秒）
1. 右指针扩张，左指针在出现重复时收缩
2. Map/Set 记窗口内字符
3. 更新最大长度

## 参考答案

### 思路
窗口 [left,right]。right 右移，若 s[right] 已在窗口，则不断 left++ 直到无重复（或用上次下标直接跳）。用 Map 存字符最近下标可 O(1) 跳 left。

### 复杂度
时间 O(n)，空间 O(字符集)

### 代码骨架（JavaScript）
```js
function lengthOfLongestSubstring(s) {
  const map = new Map();
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (map.has(ch) && map.get(ch) >= left) left = map.get(ch) + 1;
    map.set(ch, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

### 边界与追问
- 空串
- 全相同字符
- 空格/符号也算字符
