# 题 17：对称二叉树（LeetCode 101）

## 面试官可能怎么问
- 是否镜像对称？
- 如何比较两棵子树？

## 口述结构（90 秒）
1. 比较左子树和右子树是否镜像
2. 值相等且左.左 vs 右.右、左.右 vs 右.左
3. 队列两两出队也可

## 参考答案

### 思路
写函数 `isMirror(a,b)`：都空 true；一个空 false；值相等且 isMirror(a.left,b.right)&&isMirror(a.right,b.left)。根调用 isMirror(root.left, root.right)。

### 复杂度
时间 O(n)，空间 O(h)

### 代码骨架（JavaScript）
```js
function isSymmetric(root) {
  function mir(a, b) {
    if (!a && !b) return true;
    if (!a || !b || a.val !== b.val) return false;
    return mir(a.left, b.right) && mir(a.right, b.left);
  }
  return !root || mir(root.left, root.right);
}
```

### 边界与追问
- 只有根
- 结构对称值不等
- 迭代：队列每次塞入成对节点
