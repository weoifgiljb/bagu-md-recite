# 题 20：有效的括号（LeetCode 20）

## 面试官可能怎么问
- 括号是否有效？
- 栈里放什么？

## 口述结构（90 秒）
1. 遇左括号入栈
2. 遇右括号看栈顶是否匹配
3. 最后栈须空

## 参考答案

### 思路
用栈。映射 `)( ][ }{`。扫字符串：左括号 push；右括号时栈空或不匹配则 false，否则 pop。结束栈空才 true。

### 复杂度
时间 O(n)，空间 O(n)

### 代码骨架（JavaScript）
```js
function isValid(s) {
  const pair = { ')': '(', ']': '[', '}': '{' };
  const st = [];
  for (const ch of s) {
    if (ch === '(' || ch === '[' || ch === '{') st.push(ch);
    else {
      if (!st.length || st.pop() !== pair[ch]) return false;
    }
  }
  return st.length === 0;
}
```

### 边界与追问
- 空串 true
- 只有右括号
- 追问最长有效括号 → DP/栈下标
