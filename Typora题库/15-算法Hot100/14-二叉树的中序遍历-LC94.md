# 题 14：二叉树的中序遍历（LeetCode 94）

## 面试官可能怎么问
- 中序输出？
- 递归和迭代栈怎么写？

## 口述结构（90 秒）
1. 左-根-右
2. 递归最直观
3. 迭代：一路向左压栈，弹出访问再转右

## 参考答案

### 思路
递归：dfs(left), push(val), dfs(right)。迭代：cur 一路 left 入栈；栈空结束；弹出节点记录 val，cur=node.right。

### 复杂度
时间 O(n)，空间 O(h)

### 代码骨架（JavaScript）
```js
function inorderTraversal(root) {
  const res = [], stack = [];
  let cur = root;
  while (cur || stack.length) {
    while (cur) { stack.push(cur); cur = cur.left; }
    cur = stack.pop();
    res.push(cur.val);
    cur = cur.right;
  }
  return res;
}
```

### 边界与追问
- 空树
- 只有左链/右链
- Morris 遍历可 O(1) 空间（加分）
