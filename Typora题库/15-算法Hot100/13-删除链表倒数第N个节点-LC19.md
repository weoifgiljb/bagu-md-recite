# 题 13：删除链表的倒数第 N 个结点（LeetCode 19）

## 面试官可能怎么问
- 一次遍历怎么删倒数第 n 个？
- 为什么要哑节点？

## 口述结构（90 秒）
1. 快指针先走 n 步
2. 快慢一起走，快到尾时慢在待删前驱
3. 哑节点处理删头

## 参考答案

### 思路
dummy.next=head。fast 从 dummy 先走 n 步（或走 n+1 视写法），然后 slow/fast 同步，直到 fast 到末尾，slow.next 即待删，跳过即可。

### 复杂度
时间 O(L)，空间 O(1)

### 代码骨架（JavaScript）
```js
function removeNthFromEnd(head, n) {
  const dummy = { next: head };
  let fast = dummy, slow = dummy;
  for (let i = 0; i < n; i++) fast = fast.next;
  while (fast.next) { fast = fast.next; slow = slow.next; }
  slow.next = slow.next.next;
  return dummy.next;
}
```

### 边界与追问
- n=1 删尾
- n=长度 删头
- 先确认题目 n 合法
