# 题 15：二叉树的最大深度（LeetCode 104）

## 面试官可能怎么问
- 根到最远叶的节点数？
- DFS 和 BFS 哪个？

## 口述结构（90 秒）
1. DFS：1+max(左,右)
2. BFS：层数即深度
3. 空树 0

## 参考答案

### 思路
递归：空返回 0，否则 1+max(左深度,右深度)。BFS 每层 count++。

### 复杂度
时间 O(n)，空间 O(h) 或队列宽

### 代码骨架（JavaScript）
```js
function maxDepth(root) {
  if (!root) return 0;
  return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```

### 边界与追问
- 单节点深度 1
- 追问最小深度 → 注意叶节点定义
- 平衡性影响递归栈
