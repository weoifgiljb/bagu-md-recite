# 题 4：事件冒泡、捕获、委托怎么讲？

## 面试官可能怎么问

- 事件流三阶段？
- 怎么阻止冒泡？
- 委托有什么好处？

## 口述结构（90 秒）

1. 三阶段：捕获 → 目标 → 冒泡
2. `addEventListener(type, fn, { capture, once, passive })`
3. `stopPropagation` / `preventDefault` 职责不同
4. 委托：父监听 + `event.target`/`closest`，动态列表必备

## 参考答案

### 1. 事件流三阶段（对应「三阶段」）

1. **捕获（capture）**：从 `window` → 父 → … → 目标祖先  
2. **目标（target）**：到达事件目标本身  
3. **冒泡（bubble）**：目标 → … → 父 → `window`

```js
parent.addEventListener('click', fn, true)   // 捕获阶段
parent.addEventListener('click', fn, false)  // 冒泡（默认）
parent.addEventListener('click', fn, { once: true, passive: true })
```

开口顺序：**先说路径方向，再提第三个参数/`options`。**

### 2. 阻止冒泡 vs 阻止默认（对应「怎么阻止」）

```js
el.addEventListener('click', (e) => {
  e.stopPropagation()      // 别再往上冒泡（也不再继续同阶段传播）
  e.stopImmediatePropagation() // 连同一元素上后续监听也停
  e.preventDefault()       // 阻止默认：链接跳转、表单提交、右键菜单等
})
```

步骤（弹层点遮罩关闭、点内容不关闭）：  
1. 遮罩听 `click` → 关闭  
2. 内容区 `click` 里 `stopPropagation`，避免冒泡到遮罩  
3. 需要拦链接默认跳转时再用 `preventDefault`

### 3. 事件委托（对应「好处」）

**好处**：少监听器、省内存；**动态插入的子节点自动生效**；集中处理逻辑。

```js
ul.addEventListener('click', (e) => {
  const btn = e.target.closest('button.quote')
  if (!btn || !ul.contains(btn)) return
  const id = btn.dataset.msgId
  quoteMessage(id)
})
```

步骤落地：  
1. 把监听绑在**稳定父节点**（列表容器）  
2. 用 `closest` 找到业务元素  
3. 校验 `contains`，防点到容器外 portal  
4. 从 `dataset` / 属性取 id，再调业务函数

**业务例子**：对话消息列表「引用 / 复制 / 重新生成」按钮；消息流式追加也不用重新绑事件。

### 4. 和框架的关系

Vue `@click` 默认在冒泡；可用 `.capture` / `.stop` / `.prevent` 修饰符。委托思想在大列表里依然重要（或依赖组件事件）。

## 可能追问

- 捕获实际场景？→ 全局埋点、在子级之前拦截。  
- `passive: true`？→ 告诉浏览器不 `preventDefault`，优化滚动。  
- 委托能听所有事件吗？→ focus 等部分不冒泡，要用捕获或焦点委托方案。
