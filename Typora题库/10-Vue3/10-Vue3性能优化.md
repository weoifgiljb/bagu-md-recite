# 题 10：Vue3 项目性能你怎么优化？

## 面试官可能怎么问

- 首屏慢怎么查？
- 列表卡怎么治？
- 打包体积怎么砍？

## 口述结构（90 秒）

1. 先量化：Lighthouse、Performance、路由 chunk 体积
2. 运行时：虚拟列表、shallowRef、稳定 key、computed
3. 加载：路由懒加载、异步组件、图片懒加载
4. 构建：按需引入、分析打包、去重大依赖

## 参考答案

**对应问 1：首屏**
1. 看瀑布图：慢在 HTML/接口/大 JS？  
2. 路由懒加载 + 关键请求并行；非首屏组件 `defineAsyncComponent`  
3. 骨架屏降感知；压缩与 HTTP 缓存静态资源  
4. 减少主包里的编辑器/图表等重型库

**对应问 2：列表卡**
- 虚拟列表：只渲染视口附近
- `shallowRef` 放大数组，避免深代理每个对象（改项要触发整表替换或手动触发）
- 模板不做重计算，用 `computed`；事件防抖
- `v-show` 频繁切换；极少出现用 `v-if`
- 长列表勿深层 `watch(..., {deep:true})` 无必要时

**对应问 3：体积**
- Element Plus 等按需；`visualizer` 看谁最大
- 确认 tree-shaking（注意副作用标记）
- 大图 CDN/webp；locale 按需

**业务例子**
AI 对话页独立 chunk；消息虚拟滚动；流式只 patch 最后一条。
