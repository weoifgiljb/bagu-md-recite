# 题 3：水平垂直居中有哪些写法？怎么选？

## 面试官可能怎么问

- 行内 / 块级 / 未知宽高分别怎么居中？
- Flex、Grid、绝对定位 + transform 差在哪？
- 单行文字垂直居中和多行呢？
- 遇到「看起来没居中」你怎么排查？

## 口述结构（90 秒）

1. 先分场景：文字一行、盒子已知宽高、未知宽高、整页/弹层
2. 现代默认：父级 `display:flex; justify-content:center; align-items:center`（或 Grid 的 `place-items:center`）
3. 老方案：绝对定位 + `translate(-50%,-50%)`；已知宽高可用四向 0 + `margin:auto`
4. 文字：单行常靠 `line-height`≈高度；多行别硬套 line-height，用 Flex/Grid
5. 收尾：说清取舍（兼容、是否脱离文档流、是否会糊像素）

## 参考答案

### 1. 现代首选（未知宽高也稳）

```css
.wrap {
  display: flex;
  justify-content: center; /* 主轴居中 */
  align-items: center;     /* 交叉轴居中 */
  min-height: 100vh;       /* 整页垂直居中时给高度 */
}
/* 等价 Grid */
.wrap {
  display: grid;
  place-items: center;
  min-height: 100vh;
}
```

适用：按钮组、空状态、登录卡片、弹层内容区。子元素不用自己算宽高。

### 2. 绝对定位方案（弹层/水印常见）

```css
.stage { position: relative; }
.box {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%); /* 按自身宽高回退 */
}
```

- 优点：不依赖父是 Flex；子宽高可变。
- 注意：祖先有 `transform`/`filter` 时，fixed/绝对定位的 containing block 可能变；弹层常 Teleport 到 `body`。
- 奇数宽高时 `translate` 可能半像素发糊，UI 要求极严时可改 Flex。

### 3. 已知宽高：四边 0 + margin auto

```css
.box {
  position: absolute;
  left: 0; right: 0; top: 0; bottom: 0;
  width: 320px; height: 180px;
  margin: auto;
}
```

面试提一句即可：现代更少用，但能说明你懂「绝对定位盒子在约束下用 margin 自动分配剩余空间」。

### 4. 水平居中（补充）

| 场景 | 写法 |
| --- | --- |
| 块级定宽 | `margin-left: auto; margin-right: auto;` |
| 行内/行内块 | 父级 `text-align: center` |
| Flex 子项 | 父 `justify-content:center` 或子 `margin-inline: auto` |

### 5. 文字垂直居中

```css
/* 单行：行高≈容器高（只适合一行） */
.one-line { height: 40px; line-height: 40px; }

/* 多行：用 Flex，别靠 line-height */
.multi {
  display: flex;
  align-items: center;
  min-height: 80px;
}
```

### 6. 遇到问题怎么办（排查步骤）

1. **父没有高度**：`align-items:center` 看不出效果 → 给父明确高度/`min-height`，或确认父被内容撑开的方向对不对。  
2. **子被 margin 撑偏**：子有很大 `margin`，视觉不居中 → 清掉多余 margin，或改用 `gap`。  
3. **绝对定位没相对祖先**：找最近 `position` 非 `static` 的祖先；没有就相对初始包含块，看起来「乱跑」。  
4. **transform 祖先坑 fixed 弹层**：把弹层挂到 `body`，或去掉祖先 `transform`。  
5. **验收**：DevTools 量一下子盒子中心是否落在父内容盒中心；缩放 100%/125% 各看一次有无发糊。

**业务例子**：后台空列表插画居中用 Flex；模态框用 Teleport + Flex 或绝对定位居中，避免被带 `transform` 的侧栏父级影响。

## 可能追问

- `margin: auto` 在 Flex 里？→ 可以吃掉剩余空间，常用来「一端顶住、另一端推开」。
- 为什么不推荐 `table-cell` + `vertical-align`？→ 能做但语义/嵌套别扭，现代用 Flex/Grid。
- 居中和 `min-width:0`？→ Flex 子项内容过长可能撑破，居中布局里长文本子项常要 `min-width:0` + 省略。
