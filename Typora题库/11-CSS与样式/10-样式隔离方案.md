# 题 10：样式隔离有哪些方案？怎么防污染？

## 面试官可能怎么问

- 全局 CSS 会怎样？
- BEM、CSS Modules、scoped、Shadow DOM、CSS-in-JS 差在哪？
- Vue scoped 原理？深度选择器怎么用？
- 微前端/第三方弹层样式冲突怎么处理？
- 如何选？

## 口述结构（90 秒）

1. 目标：避免互相覆盖，同时保留主题/工具类能力
2. 约定型：BEM 命名；构建型：CSS Modules / Vue scoped；运行时：Shadow DOM、CSS-in-JS
3. 讲清原理：scoped 加属性选择器；Modules 把类名哈希
4. 冲突现场：DevTools 看谁覆盖；微前端用命名空间/Shadow/前缀
5. 选择：组件库偏 Modules/scoped；强封装 Web Component 用 Shadow；工具类可全局

## 参考答案

### 1. 方案对比（面试表）

| 方案 | 原理 | 优点 | 代价 |
| --- | --- | --- | --- |
| BEM | `.block__el--mod` 约定 | 无构建依赖 | 靠人，易飘 |
| CSS Modules | 类名编译成哈希 | 局部默认 | 动态类要 `:global` |
| Vue `scoped` | 加 `data-v-xxxx` | 用着顺 | 改子组件需 `:deep` |
| Shadow DOM | 影子树隔离 | 真隔离 | 穿透主题/选节点麻烦 |
| CSS-in-JS | 运行时/编译插样式 | 随组件态 | 运行时成本/生态偏好 |
| iframe | 文档隔离 | 最硬 | 通信/高度麻烦 |

### 2. 原理示意

**Vue scoped 编译后类似：**

```css
.button[data-v-abc123] { color: red; }
```

**CSS Modules：**

```css
/* 源 .button → 产物 .Button_button_x7f2 */
```

```jsx
import s from './Button.module.css';
<button className={s.button} />
```

**Shadow DOM：**

```js
host.attachShadow({ mode: 'open' });
// 外部选择器默认进不来影子内部
```

### 3. 遇到问题怎么办

**场景 A：改了子组件样式不生效（Vue scoped）**

```vue
<style scoped>
/* 穿透到子根 */
:deep(.child-title) { color: var(--color-text); }
</style>
```

1. 确认类是否在子组件根上。  
2. 优先用子组件暴露的 props/variant，而不是层层 `:deep`。  
3. 第三方组件看是否提供 `overlayClassName` / `popupClassName`（弹层挂 body 时 scoped 本来够不着）。

**场景 B：弹层挂到 body，类名丢了/样式没了**

1. 现象：Modal 在 `body` 下，Modules 类在，但你写的父级后代选择器失效。  
2. 处理：给弹层传 `className`；或准备全局 `.app-modal` 层；或 Teleport 后仍用模块类打在弹层根上。

**场景 C：微前端子应用互盖**

1. 前缀：`#subapp-a .btn` 或构建加 `namespace`。  
2. 严格 Modules；或 Shadow；或 iframe。  
3. 共享组件抽到主应用，统一 token。  
4. 排查：看加载顺序与更高特异性全局样式。

**场景 D：要主题又要隔离**

- 组件内用 `var(--color-primary)`，变量在外层提供；隔离的是「类名」，不是「设计 token」。

### 4. 怎么选（收尾）

- 业务 Vue/React SPA：`scoped` / CSS Modules + 少量全局 reset/工具类。  
- 设计系统：Modules + CSS 变量 token。  
- 浏览器插件/嵌入第三方页：Shadow DOM 或 iframe。  
- 不要「为了隔离」上 CSS-in-JS，看团队栈。

**业务例子**：Taro/小程序注意平台样式与类名；中后台 Table 滚动条样式用明确类前缀，避免 `div::-webkit-scrollbar` 全局误伤。

## 可能追问

- `:global` 何时用？→ 改第三方或真正全局动画 keyframes。  
- 属性选择器性能？→ 现代可忽略，别过早优化。  
- Tailwind 算隔离吗？→ 原子类全局但冲突面不同，靠约定与 layer。
