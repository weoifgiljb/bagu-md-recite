# 题 17：伪类和伪元素有什么区别？

## 面试官可能怎么问

- `:` 和 `::`？
- ::before 常用来干嘛？
- :nth-child 和 :nth-of-type？

## 口述结构（90 秒）

1. 伪类：选「处于某种状态」的真实元素（`:hover` `:focus` `:nth-child`）
2. 伪元素：造出「假元素」装装饰/内容（`::before` `::after` `::placeholder`）
3. 老写法伪元素也可用单冒号；新规范伪元素建议双冒号 `::`
4. `::before/after` 必须有 `content`（可空字符串）；可画线、图标、清浮动

## 参考答案

### 1. `:` 和 `::`？（对应第 1 问）

- **伪类**用单冒号：`:hover`、`:focus-visible`、`:disabled`、`:nth-child()`。
- **伪元素**用双冒号：`::before`、`::after`、`::first-line`、`::placeholder`。
- 兼容：老浏览器里 `::before` 写成 `:before` 也能跑；**新代码伪元素写 `::`**，面试说清即可。

```css
.btn:hover { opacity: 0.9; }          /* 伪类：真实 button 的状态 */
.btn::before { content: ""; }         /* 伪元素：多出一个盒子 */
```

### 2. ::before 常用来干嘛？（对应第 2 问）

- 装饰：小圆点、竖分隔线、必填星号、角标底。
- 清浮动：`.clearfix::after { content:""; display:table; clear:both; }`。
- 图标：简单几何用 border/背景；复杂 SVG 更建议 `<img>`/`mask`/图标组件。

```css
.required::before {
  content: "*";
  color: #ef4444;
  margin-right: 4px;
}
.divider::after {
  content: "";
  display: block;
  height: 1px;
  background: #eee;
  margin-top: 8px;
}
```

**注意**：伪元素不在 DOM 树里，**基本不能直接 `querySelector` / 绑事件**；要可点区域就用真实节点。

### 3. :nth-child 和 :nth-of-type？（对应第 3 问）

- `:nth-child(2n)`：在**所有子节点**里数第 n 个，再看是不是你写的标签。
- `:nth-of-type(2n)`：只在**同标签名**的兄弟里数。

```html
<div>
  <h3>标题</h3>
  <p>A</p>
  <p>B</p>
</div>
```
```css
p:nth-child(2) { }    /* 命中 A：第 2 个子刚好是 p */
p:nth-child(1) { }    /* 不中：第 1 个是 h3 */
p:nth-of-type(1) { }  /* 命中 A：第 1 个 p */
```

**遇见问题 → 怎么办**：斑马纹「错位」→ 中间插了别的标签，改用 `:nth-of-type` 或给列表项统一包一层。

## 可能追问

- `:is` / `:where` / `:has`？→ `:is` 取列表最高特异性；`:where` 特异性 0；`:has` 父选子条件（注意性能与支持）。
- 伪元素能绑 JS 事件吗？→ 基本不能当 DOM 节点操作。
- `content` 能放图片吗？→ `content: url(...)` 可以，但可访问性/控制力不如真实标签。
