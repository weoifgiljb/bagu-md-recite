# 题 15：浮动（float）是什么？怎么清除浮动？

## 面试官可能怎么问

- 浮动当初解决什么问题？
- 高度塌陷怎么清？
- 现在还用 float 做布局吗？

## 口述结构（90 秒）

1. float 让元素脱离普通流，向左/右排布，文字可环绕
2. 父元素若只有浮动子元素，高度常塌成 0（背景/边框包不住）
3. 清除：父级建 BFC（`flow-root` / `overflow`）、clearfix 伪元素、`clear:both`
4. 现代布局优先 Flex/Grid；float 多用于**图文环绕**，少用于整页栅格

## 参考答案

### 1. 浮动当初解决什么问题？（对应第 1 问）

- 早期需求：文字环绕图片、简易多列。
- 机制：元素进入「浮动流」，后续行盒会围绕它；**普通流父级不算浮动子的高度**（除非清浮动/开 BFC）。
- 副作用：高度塌陷、后面的块跑到浮动旁、布局难维护。

### 2. 高度塌陷怎么清？（对应第 2 问）

**现象**：卡片里头像 `float:left`，父盒子高度变 0，灰底/边框消失。

**遇见问题 → 怎么办**
1. 确认子元素是否 `float`（DevTools 看 computed）。
2. **优先给父级**开 BFC 或 clearfix，不要只给子元素乱加属性。
3. 验收：父高度包住内容；后续兄弟不再钻进浮动旁边（除非你要环绕）。

```css
/* 推荐：专门为 BFC */
.card { display: flow-root; }

/* 老项目常见 */
.card { overflow: hidden; } /* 注意：可能裁阴影/影响 sticky */

/* clearfix */
.clearfix::after {
  content: "";
  display: table; /* 或 block */
  clear: both;
}

/* 清「后面那个兄弟」贴到浮动旁 */
.footer { clear: both; }
```

### 3. 现在还用 float 做布局吗？（对应第 3 问）

- **整页/后台栅格**：基本不用，改 Flex/Grid。
- **仍合理**：文章封面图 `float:left; margin-right:12px`，正文环绕。
- 面试加分：能讲清塌陷原理，再说「新布局优先 Flex」。

```css
/* 现代两栏，别用 float */
.row { display: flex; gap: 16px; }
.aside { flex: 0 0 200px; }
.main { flex: 1; min-width: 0; }
```

## 可能追问

- float 后的元素是 BFC 吗？→ 浮动元素会创建 BFC。
- 和绝对定位脱离文档流差别？→ `absolute/fixed` 不占普通流位置；float 仍影响环绕与浮动流占位。
- `overflow:hidden` 清浮动的副作用？→ 裁切溢出、可能让内部 sticky 失效。
