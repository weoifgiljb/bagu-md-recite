# 题 33：两栏等高、粘页脚（sticky footer）怎么做？

## 面试官可能怎么问

- 内容少时页脚吸底？
- 内容多时页脚跟随？
- 等高列？

## 口述结构（90 秒）

1. **粘页脚**：整页当一列 Flex/`min-height:100vh`，中间 `flex:1` 撑开；内容少页脚贴视口底，内容多自然被顶下去跟随文档
2. **Grid 同理**：`grid-template-rows: auto 1fr auto`
3. **两栏等高**：Flex/Grid 默认交叉轴 `stretch`，左右栏背景/边框自然一样高；别再靠 JS 量高度或表格布局
4. 收尾：`position:sticky` 是滚动吸顶，和 sticky footer（布局结构）不是一回事

## 参考答案

### 1. 粘页脚：内容少吸底、内容多跟随（同一套结构）

目标：页脚始终在「整页内容的底部」。内容不够一屏时贴视口底；超过一屏时跟在正文后面（用户要滚到底才看到）。

**推荐：整页列方向 Flex**

```html
<body class="page">
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
```

```css
html, body { height: 100%; margin: 0; }
.page {
  min-height: 100vh;          /* 至少一屏；也可用 100dvh 避开移动端地址栏跳动 */
  display: flex;
  flex-direction: column;
}
.page main {
  flex: 1 1 auto;             /* 吃掉剩余高度 → 内容少时把 footer 顶到视口底 */
  min-height: 0;              /* 主区内部再滚动时防止撑破 */
}
.page header,
.page footer {
  flex: 0 0 auto;             /* 头尾按内容高度，不被压缩 */
}
```

**Grid 写法（同样满足少/多两种情况）**

```css
.page {
  min-height: 100vh;
  display: grid;
  grid-template-rows: auto 1fr auto; /* 头 / 主(吃剩余) / 脚 */
}
```

验收：
- 正文只有两三行 → footer 仍在屏幕底部；
- 正文很长 → footer 在文档末尾，不会「浮」在正文中间。

### 2. 两栏等高

**Flex（后台侧栏 + 主内容常见）**

```css
.layout {
  display: flex;
  align-items: stretch; /* 默认就是 stretch，可省略；交叉轴拉齐 */
  gap: 16px;
  min-height: 400px;    /* 或由内容决定 */
}
.aside {
  flex: 0 0 240px;
  background: #f5f5f5;
}
.main {
  flex: 1;
  min-width: 0;         /* 防长内容撑破，见题 39 */
  background: #fff;
}
```

**Grid**

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  align-items: stretch; /* 默认 */
}
.aside, .main { /* 背景铺满整列高度即可 */ }
```

等高本质：同一行 Flex/Grid 项交叉轴被拉伸到行高。若某栏内部还要「自己滚动」，给该栏 `overflow:auto` + `min-height:0`（Grid/Flex 子项）。

### 3. 决策口诀

| 需求 | 做法 |
| --- | --- |
| 粘页脚 | 页面列 Flex/`1fr` 中间行，不要给 footer 写 `position:fixed` 冒充 |
| 两栏等高 | Flex/Grid + stretch；新项目别用 table 或 JS 同步高度 |
| 滚动吸顶表头 | 才用 `position: sticky; top: 0` |

## 可能追问

- sticky footer 和 `position: sticky` 区别？→ 前者是整页布局把脚推到底；后者是滚动时元素在容器内吸顶/吸底。
- 为啥不用 `footer { position:fixed; bottom:0 }`？→ 会盖住正文末尾，还要给 main 预留 padding-bottom；内容多时体验差。
- `100vh` 在移动端？→ 地址栏显隐会导致跳动，可试 `100dvh` 或 `min-height: 100%` 链路。
