# 题 26：CSS 精灵图、字体图标、SVG 怎么选？

## 面试官可能怎么问

- sprite 优点？
- iconfont 坑？
- 为什么现在偏 SVG？

## 口述结构（90 秒）

1. Sprite：多图合并，一次请求，用 `background-position` 裁切
2. iconfont：矢量、易改色，但基线对齐、隐私模式下字体失败、多色难
3. SVG / SVG sprite / 组件化图标：清晰、可访问、按需加载、多色友好
4. 选型：现代站默认 SVG 组件；HTTP/2 下 sprite 减请求收益变小；极老项目才维护大雪碧图

## 参考答案

### 1. Sprite（CSS 精灵图）怎么做

```css
.icon {
  width: 24px;
  height: 24px;
  background: url(icons.png) no-repeat;
  background-size: 96px 24px; /* 按设计倍率算 */
}
.icon-home { background-position: 0 0; }
.icon-user { background-position: -24px 0; }
.icon-set  { background-position: -48px 0; }
```

步骤：设计导出大图 → 构建工具生成坐标（或手写）→ 用类名切图。

**优点**：HTTP/1.1 时代明显减少请求；缓存一次全有。  
**缺点**：改一个图标可能动整图；视网膜要 2x 图；语义/无障碍差；HTTP/2 多路复用后收益下降。

### 2. iconfont 坑（必答）

```html
<i class="iconfont icon-home" aria-hidden="true"></i>
```

```css
.iconfont {
  font-family: "iconfont" !important;
  font-style: normal;
  -webkit-font-smoothing: antialiased;
}
```

常见坑：
1. **基线对齐**：和文字并排时上下偏，要调 `vertical-align` 或改 flex。  
2. **字体加载失败 / 跨域 / 隐私模式**：整片图标变「方框」或空白。  
3. **多色图标**：字体单色为主，多色要叠字或放弃。  
4. **可访问性**：纯图标按钮必须有 `aria-label` / 可见文字。  
5. **缓存与版本**：换一套码点，旧 CSS 对不上。

### 3. 为什么现在偏 SVG

```jsx
// React：SVG 组件，currentColor 跟文字色
function IconHome(props) {
  return (
    <svg width="1em" height="1em" viewBox="0 0 24 24" aria-hidden="true" {...props}>
      <path fill="currentColor" d="M10 20v-6h4v6h5v-8h3L12 3 2 12h3v8z" />
    </svg>
  );
}
// 使用：<button aria-label="首页"><IconHome /></button>
```

| 需求 | 更合适 |
| --- | --- |
| 单色 UI 图标、要跟随主题色 | SVG + `currentColor` |
| 多色插画 / 复杂图 | 图片或多色 SVG |
| 海量装饰小图、老项目 | 可继续 sprite |
| 要 SEO / 读屏认识内容图 | 内容用 `<img>`，装饰用 SVG/CSS |

```css
/* 单色蒙版图标备选 */
.icon-mask {
  width: 24px; height: 24px;
  background-color: currentColor;
  -webkit-mask: url(home.svg) center / contain no-repeat;
  mask: url(home.svg) center / contain no-repeat;
}
```

业务例子：后台管理系统图标用 SVG 组件库（或 Iconify）；营销页大插画用 WebP/AVIF；只有遗留后台才维护 sprite。

## 可能追问

- 雪碧图和 base64？→ 极小图标可 data URI 内联，注意 HTML/CSS 体积与缓存粒度。
- SVG sprite（`<symbol>` + `<use>`）？→ 一份定义多处复用，注意外链 `use` 的旧浏览器/跨域限制。
- 和图片 `srcset`？→ 位图方案；图标矢量优先 SVG。
