# 题 22：单行 / 多行文本溢出省略怎么写？

## 面试官可能怎么问

- 单行 ellipsis？
- 多行 -webkit-line-clamp？
- 兼容性？

## 口述结构（90 秒）

1. 单行：`overflow:hidden` + `white-space:nowrap` + `text-overflow:ellipsis`
2. 多行：`-webkit-box` + `-webkit-line-clamp` + `overflow:hidden`（现已很普及）
3. 必须有宽度约束（块宽/ flex 子 `min-width:0`），否则不触发
4. 表格单元格、Flex 子项是高频翻车点

## 参考答案

### 1. 单行 ellipsis？（对应第 1 问）

```css
.one-line {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

三件套缺一不可：不 `nowrap` 会换行；不 `hidden` 裁不到；不 `ellipsis` 没有省略号。

### 2. 多行 -webkit-line-clamp？（对应第 2 问）

```css
.multi-line {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
  overflow: hidden;
  /* 可选：标准属性渐好，可并存 */
  line-clamp: 2;
}
```

**展开/收起**
```css
.multi-line.is-open {
  -webkit-line-clamp: unset;
  display: block; /* 视情况恢复 */
}
```
用 JS 切 class 即可。

### 3. 兼容性与踩坑？（对应第 3 问）

- 单行：所有现代浏览器稳。
- 多行：`-webkit-line-clamp` 在 Chromium / Safari / 新 Firefox 都可用；极老环境要 JS 截断或接受不省略。
- **必须有宽度**：父 flex 时子项默认 `min-width:auto`，长文本会撑开 → 子项加 `min-width:0`（或 `overflow:hidden`）。

```css
.row { display: flex; }
.row .title {
  flex: 1;
  min-width: 0; /* 关键 */
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

**遇见问题 → 怎么办**
| 现象 | 处理 |
| --- | --- |
| 没有出现 … | 检查宽度是否无限；Flex 加 `min-width:0` |
| 多行不生效 | 确认 `-webkit-box-orient: vertical` 没被自动前缀插件删掉 |
| 表格 `td` 不省略 | `table-layout:fixed` + `td` 设宽 + 三件套 |
| 要响应式行数 | 媒体查询改 `-webkit-line-clamp` |

**业务例子**：列表标题单行省略；卡片摘要两行 clamp；详情页「展开」切 class。

## 可能追问

- 响应式行数？→ 媒体查询或容器查询改 clamp 值。
- 省略后还要 tooltip？→ `title` 属性或组件 Library 的 Ellipsis + Popup。
- `word-break`？→ 中英文混排可配 `overflow-wrap: anywhere` / `word-break: break-all`（慎用）。
