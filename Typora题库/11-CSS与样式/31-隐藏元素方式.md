# 题 31：隐藏元素有哪些方式？差异？

## 面试官可能怎么问

- display:none 和 visibility:hidden？
- opacity:0 还能点吗？
- 无障碍隐藏？

## 口述结构（90 秒）

1. `display:none`：不占位、不渲染进布局，不可交互
2. `visibility:hidden`：占位，不可交互；子孙可再 `visible`
3. `opacity:0`：占位且默认可点中，要关交互加 `pointer-events:none`
4. 移出屏幕 / `clip` / HTML `hidden`；读屏专用 **sr-only**；动画离开用 opacity，而不是直接 display

## 参考答案

### 1. 对比表（必背）

| 方式 | 占位 | 可点击 | 读屏 | 可过渡动画 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| `display:none` | 否 | 否 | 通常忽略 | 否（无法过渡 display） | 条件卸载式隐藏 |
| `visibility:hidden` | 是 | 否 | 一般不可感知 | visibility 可过渡 | 占位隐藏 |
| `opacity:0` | 是 | **是**（默认） | 仍可能读到 | 是 | 淡入淡出 |
| `hidden` 属性 | 否（近似 display:none） | 否 | 忽略 | 否 | 原生隐藏 |
| 移出屏 / `sr-only` | 视觉无 | 视实现 | **故意留给读屏** | — | 无障碍文本 |
| `clip-path` / 尺寸 0 | 看写法 | 看写法 | 看写法 | 可 | 特殊裁切 |

### 2. 关键代码

```css
.is-gone { display: none; }

.is-invisible {
  visibility: hidden; /* 仍占着那一块 */
}

.is-faded {
  opacity: 0;
  pointer-events: none; /* 关键：关掉点击 */
}

[hidden] { display: none; }
```

```html
<button hidden>暂不可用</button>
```

**opacity:0 还能点吗？**  
能。透明只是视觉，命中测试还在。必须同时：

```css
.ghost { opacity: 0; pointer-events: none; }
```

若还在 tab 序里，可加 `tabindex="-1"` 或直接 `visibility/display` 处理。

### 3. 无障碍隐藏（sr-only）

视觉隐藏但读屏要读（「跳到主内容」等）：

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
/* 现代也可：clip-path: inset(50%); */
```

```html
<a href="#main" class="sr-only">跳到主内容</a>
```

不要用 `display:none` 做「读屏专用文案」——读屏也拿不到。

### 4. 和 Vue / 动画

- `v-if` ≈ 销毁 / 不渲染（接近 display 无）  
- `v-show` ≈ `display:none` 切换  
- 离场动画：先过渡 `opacity`/`transform`，**动画结束再** `display:none`（`<Transition>`）

业务例子：Modal 遮罩用 opacity；路由级卸载用 display/v-if；图标旁补读屏文字用 sr-only。

## 可能追问

- 子孙 `visibility:visible`？→ 可以在 hidden 祖先下再显示某子节点（仍占祖先布局）。
- `content-visibility`？→ 渲染优化，不是普通「隐藏交互」手段。
- 动画为什么不用 display？→ `display` 非插值属性，无法平滑过渡。
