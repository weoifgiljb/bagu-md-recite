# 题 18：左右固定、中间自适应的三栏布局怎么做？

## 面试官可能怎么问

- 圣杯 / 双飞翼知道吗？
- Flex / Grid 怎么写？
- 兼容性怎么选？

## 口述结构（90 秒）

1. 老方案：float 圣杯 / 双飞翼（面试可能考原理）
2. 现代：Flex（两边定宽，中间 `flex:1`）或 Grid（`200px 1fr 200px`）
3. 优先现代方案；能讲清负 margin 老方案加分
4. 中间栏务必 `min-width:0`（或 Grid 的 `minmax(0,1fr)`）防溢出

## 参考答案

### 1. 圣杯 / 双飞翼？（对应第 1 问）

- **目标**：左右定宽、中间自适应，且中间栏优先渲染（SEO/首屏，老话题）。
- **圣杯**：三列都 float；父 `padding` 留左右槽；左右列用负 margin 拉到两侧，再用 `relative` + `left/right` 放进槽。
- **双飞翼**：中间栏再包一层，用中间内层 `margin-left/right` 腾出左右宽度，左右列负 margin 拉上去（少用 relative）。
- **今天**：能说清「负 margin 把左右栏提行」即可；项目里别新写。

### 2. Flex / Grid 怎么写？（对应第 2 问）

**Flex（最常用口述）**
```css
.row { display: flex; gap: 16px; }
.side { width: 200px; flex: none; }
.main { flex: 1; min-width: 0; } /* 防长词/子项撑破 */
```

**Grid**
```css
.row {
  display: grid;
  grid-template-columns: 200px minmax(0, 1fr) 200px;
  gap: 16px;
}
```

**HTML 顺序**（现代不必强求中间优先，可读性优先）
```html
<div class="row">
  <aside class="side">左</aside>
  <main class="main">中</main>
  <aside class="side">右</aside>
</div>
```

### 3. 兼容性怎么选？（对应第 3 问）

| 场景 | 选型 |
| --- | --- |
| 现代浏览器 / 内部后台 | Flex 或 Grid |
| 要等高列 | Flex/Grid 天生等高 |
| 面试手写 | 先写 Flex，再补一句圣杯原理 |
| 极老 IE | 才考虑 float 方案（现在很少） |

**遇见问题 → 怎么办**
1. 中间内容把布局撑破：给 `.main` 加 `min-width:0`，内部滚动区 `overflow:auto`。
2. 小屏三栏挤爆：媒体查询改单列，`grid-template-columns: 1fr` 或 `flex-direction:column`。

## 可能追问

- 圣杯核心？→ 负 margin 把左右栏拉到与中间同一行 + padding/相对定位进槽。
- 等高？→ Flex/Grid 默认拉伸对齐。
- 中间优先 DOM？→ 老 SEO 话题；现在更关心无障碍与 CSS 顺序，可用 `order` 但要慎重。
