# 题 24：响应式布局你会怎么做？

## 面试官可能怎么问

- 移动优先还是桌面优先？
- 断点怎么定？
- 和 rem/vw 关系？

## 口述结构（90 秒）

1. 先流体：`%` / `flex` / `grid` / `minmax`，再用 `@media` 补断点
2. **移动优先**：默认小屏样式，用 `min-width` 往上增强；桌面优先则 `max-width` 往下砍
3. 断点跟设计稿档位（如 375 / 768 / 1024），别无脑抄 Bootstrap 数字
4. 字号与间距用 rem/token；视口相关用 vw/`clamp`；组件级用 `@container`

## 参考答案

### 1. 整体步骤（能落地）

1. 定内容优先级：小屏先保核心路径（列表、主按钮），侧栏改抽屉。  
2. 布局用流体：栅格 `grid-template-columns: 1fr` → 大屏变多列；少写死 px 宽。  
3. 加断点增强：导航从汉堡 → 横排；卡片从 1 列 → 2/3 列。  
4. 图片与媒体：`max-width:100%`、`srcset`/`picture`；防 CLS 用 `aspect-ratio`。  
5. 验收：真机/DevTools 多宽；看横向滚动、点触热区 ≥ 44px。

### 2. 移动优先 vs 桌面优先

```css
/* 移动优先（推荐）：默认 = 小屏 */
.card { display: grid; gap: 12px; grid-template-columns: 1fr; }
@media (min-width: 768px) {
  .card { grid-template-columns: 1fr 1fr; }
}
@media (min-width: 1200px) {
  .card { grid-template-columns: repeat(3, 1fr); }
}

/* 桌面优先：默认 = 大屏，再往下覆盖 */
.nav__links { display: flex; }
@media (max-width: 767px) {
  .nav__links { display: none; } /* 小屏藏起，改汉堡 */
}
```

面试怎么说：新项目我用**移动优先 + min-width**，样式只「加能力」不「拆能力」，覆盖更少、好维护。

### 3. 断点怎么定

- 跟设计稿：常见 375（手机）、768（平板）、1024/1280（桌面）。  
- 跟内容：在「布局要换行/侧栏要收起」的临界宽度打断点，而不是死背设备名。  
- 少而稳：2～4 个够用；同一套 token（间距、字号）跨断点复用。

```css
/* 侧栏示例：小屏抽屉，大屏固定 */
.layout { display: block; }
.sidebar { position: fixed; inset: 0 auto 0 0; width: 280px; transform: translateX(-100%); }
.sidebar.is-open { transform: none; }
@media (min-width: 1024px) {
  .layout { display: grid; grid-template-columns: 240px 1fr; }
  .sidebar { position: sticky; top: 0; height: 100vh; transform: none; }
}
```

### 4. 和 rem / vw 的关系

| 手段 | 管什么 | 注意 |
| --- | --- | --- |
| `%` / flex / grid | 布局比例 | 父宽要明确；`min-width:0` 防撑破 |
| `rem` | 字号、间距随根字号 | 常配合 html 字号或 `clamp` |
| `vw` / `clamp` | 随视口微调 | 过大过小要设上下限 |
| `@media` | 整页档位切换 | 改的是「布局模式」 |
| `@container` | 组件随**父容器**变 | 卡片在侧栏/主栏表现不同时很香 |

```css
html { font-size: 16px; }
.title {
  font-size: clamp(1.25rem, 2vw + 1rem, 2rem);
}
@container (min-width: 400px) {
  .product-card { grid-template-columns: 120px 1fr; }
}
```

业务例子：管理台小屏侧栏变抽屉，大屏固定；卡片栅格 `1 → 2 → 3` 列，同一套 spacing token。

## 可能追问

- container queries？→ `@container` 按**父容器**宽度，不是视口；适合组件库。
- 打印样式？→ `@media print`，藏导航、去阴影、链露出 URL。
- `meta viewport`？→ 移动端必须：`width=device-width, initial-scale=1`，否则媒体查询全乱。
