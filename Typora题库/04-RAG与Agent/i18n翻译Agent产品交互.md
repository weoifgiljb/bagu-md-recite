# 题 17：i18n/翻译 Agent 产品交互与指标怎么讲？

## 面试官可能怎么问

- 批量 key、对照评测，页面怎么交互？
- 132→52、下降约 60.6% 怎么表述才不夸大？
- 和「准确率 60%」有什么区别？

## 先自己答（90 秒）

## 参考答

**产品交互**
- 导入/选择 key 集合 → 跑翻译 Agent → 表格：source | target | 状态
- 质检 Agent：错误列表（类型、key、建议）；支持筛选未解决
- 对照评测：抽检集上对比「机译 vs 人工/基线」；可并排 diff

**指标怎么讲（重要）**
- 证据：**质检错误数**从 132 降到 52，降幅约 **(132-52)/132 ≈ 60.6%**
- 正确表述：「质检发现问题数下降约 60.6%」，或「错误存量减少」
- **不要**说成「翻译准确率提升到 60.6%」或「模型准确率 60%」——那是不同度量
- 补充上下文：规则版本、语种、样本范围；避免把单次实验说成全局 SLA

**面试加分**：主动区分 precision/业务错误数/人工抽检通过率；承认 Agent 是人机闭环不是全自动零错误。

## 可能追问

- 批量失败重跑？→ 按失败 key 子集重试，保留成功行。
