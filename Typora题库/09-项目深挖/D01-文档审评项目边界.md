# 题 10：文档审评：实习小程序 vs Taro 实验台，边界怎么说？

## 面试官可能怎么问

- 你实习做的是原生还是 Taro？
- 评论/AI/个人中心能说是实习上线的吗？
- 三仓架构怎么介绍？

## 口述结构（90 秒）

1. 实习：原生小程序 + wxParse 列表/详情主路径
2. doc-review-taro：Taro 实验台，勿说成实习已上线
3. 三仓：db / functions / taro
4. 开口模板：实习交付 + 后来实验台跑通契约

## 参考答案

### 对应问 1：原生还是 Taro

**诚实口径**
- **实习交付**：原生微信小程序 + **wxParse**，列表/详情主路径
- **后来**：`doc-review-taro`（Taro React）作**实验台**，把筛选、请求态、AI 对话契约跑通，方便复盘

### 对应问 2：评论 / AI / 个人中心能说实习上线吗

**不能。** 这些多为实验台扩展。

面试句：
「实习上线的是列表详情与请求态；评论、AI Tab、个人中心是我在 Taro 实验台补齐契约与交互，方便复盘，不是实习当时已全量上线。」

### 对应问 3：三仓架构

| 仓 | 职责 |
| --- | --- |
| `doc-review-db` | Prisma schema / 迁移 / 种子 |
| `doc-review-functions` | NestJS API + Swagger + AdminJS |
| `doc-review-taro` | 微信小程序前端（实验台） |

开口：「后端契约在 Nest；运营用 AdminJS 管 Doc；小程序消费只读文档与 `POST /api/ai/chat`。」
