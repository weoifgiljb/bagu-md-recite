# 题 2：「错误数下降约 60.6%」口径怎么讲才不翻车？

## 面试官可能怎么问

- 你说准确率提升 60% 可以吗？
- 132→52 怎么算？样本是什么？
- 被追问评测偏差时你怎么答？

## 口述结构（90 秒）

1. 唯一正确说法：错误数降幅，不是准确率提升
2. 公式：(132-52)/132 ≈ 60.6%
3. 样本：同一批新人引导页 key 的对照评测
4. 归因诚实：翻译链路贡献 + 不独占质检/人工终审

## 参考答案

### 对应问 1：能不能说「准确率提升 60%」

**不能。** 正确说法只有：

> 同一批新人引导页 key 的对照评测中，错误数从 132 降到 52，**(132−52)/132 ≈ 60.6%**，即 **错误数下降约 60.6%**。

「准确率提升 60%」是另一套定义（需要正确条数/总条数前后对比），没有这套数据就不要说。

### 对应问 2：132→52 怎么算、样本是什么

步骤（口述）：
1. 固定同一批 key（新人引导页相关）
2. 对照评测：机翻/旧链路 vs 当前翻译链路（含结构/术语保护）
3. 按评测表计「错误条数」：132 → 52
4. 降幅 = 减少量 / 原错误数

**样本归属**：评测表由质检侧制定；用户工单与市场同事参与标注。开口要带上「评测协作」，避免「我自己标的 132」。

### 对应问 3：评测偏差被追问

诚实清单（没有就说没有，不编）：
- 总 key 数、语言范围、错误分类计数
- 是否盲评、质检前后是否各测一次
- 人工终审占比

稳妥句：
「我归因到翻译链路的结构/术语保护与失败重翻；人工终审和质检 agent 的贡献不独占。待补的数据有总 key 数和分类明细，目前对外只报错误条数降幅。」


## 可能追问

- 错误类型怎么分？→ 结构（占位符/标签）/ 术语 / 语义；没有分类表就说「按评测表三类」。
- 有没有对照组语言？→ 有则说语种集合；没有则承认单批对照。
- 质检前后各测一次吗？→ 对照评测是同一批前后比；具体节奏跟质检侧。
