# 题 5：结构 / 术语 / 语义为什么必须分层？术语误命中怎么防？

## 面试官可能怎么问

- 为什么不合成一个大 prompt？
- matchExactTerm 规则是什么？
- D51 这类误命中你怎么处理？

## 口述结构（90 秒）

1. 三类问题检测手段不同，不能靠一次模型自评
2. 结构证壳 → 术语证词 → 语义证意（质检/人工）
3. matchExactTerm：整串唯一才直填
4. 误命中：宁可不替；回归用例锁规则

## 参考答案

### 对应问 1：为什么不合成一个大 prompt

| 层 | 证什么 | 失败后果 | 检测手段 |
| --- | --- | --- | --- |
| 结构 | 占位符/标签/转义/重复 | 页面直接炸 | 规则/壳校验，确定性 |
| 术语 | 品牌与产品口径 | 错译品牌词 | 词表精确命中 |
| 语义 | 理解是否偏 | 体验差、误导 | 质检侧 / 人工，不与翻译自嗨混 |

合成一个 prompt 的问题：模型会「自证正确」；结构错误应用确定性校验，不该交给同一轮自评。

### 对应问 2：matchExactTerm 规则

1. 对源文 `trim`
2. **整串唯一**命中术语表才允许直填
3. 子串命中不算：`聊天`✓，`开始聊天`✗（避免半词误替换）
4. 宁可不替，走模型 + 术语约束，也不半替换

### 对应问 3：误命中（如 D51）怎么处理

步骤：
1. 复现：哪条源文被错误直填/替换
2. 收紧规则：整串匹配、长短语优先、禁用模糊子串
3. 加回归用例：误命中样本进测试集
4. 已回填错误：按 `i18n_key` 重跑或人工纠；结构已过但页面语义错 → **看页面**对 key，不在源码里瞎猜

**从 UI 发现语义问题**：结构校验已过且已回填 → 打开目标页核对 → 回填后按标签定位 key。


## 可能追问

- 富文本标签怎么保护？→ 译前抽壳/占位，译后还原；校验标签集合不变。
- 多义词术语？→ 带页面/模块上下文进 prompt；词表加 domain 字段。
- 误命中回归用例？→ 至少覆盖「子串误替」「大小写/空格」「含标点」。
