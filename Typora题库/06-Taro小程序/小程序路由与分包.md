# 题 6：小程序路由怎么跳？分包怎么配？主包过大怎么办？

## 面试官可能怎么问

- navigateTo / redirectTo / switchTab / reLaunch 区别？
- tabBar 页面有哪些限制？
- subPackages 怎么划？预下载怎么做？

## 口述结构（90 秒）

1. 先分清「栈内推入」还是「切 tab」还是「重启」
2. tab 页只能 switchTab；不能把 tab 当普通页 navigateTo
3. 主包只留启动与 tab；业务页进分包降体积
4. AI/低频模块优先独立分包；注意公共依赖归 independent 还是放到主包

## 参考答案

### 1. 路由 API 对照

| API | 行为 | 栈 | 典型场景 |
| --- | --- | --- | --- |
| navigateTo | 推入新页 | +1 | 列表→详情 |
| redirectTo | 关当前再开 | 替换 | 中转页、防回退 |
| navigateBack | 返回 | -n | 详情回列表 |
| switchTab | 切 tab | 清非 tab 栈 | 底栏切换 |
| reLaunch | 关所有再开 | 重置 | 登录后进首页 |
| exitMiniProgram | 退出 | — | 少用 |

```ts
// 详情
Taro.navigateTo({ url: `/pages/detail/index?id=${id}` })
// 回首页 tab
Taro.switchTab({ url: '/pages/home/index' })
```

页面栈有层数限制（常见约 10 层）；过深用 redirect 或设计扁平信息架构。

### 2. 分包配置步骤

1. `app.config` 里 `pages` 只放主包（启动页 + tab 页优先）。  
2. `subPackages: [{ root: 'packageAi', pages: ['pages/chat/index', ...] }]`。  
3. 跳转路径写完整：`/packageAi/pages/chat/index`。  
4. 公共组件：主包引用多分包 → 易打进主包；可复制轻量版或独立分包。  
5. `preloadRule`：在列表页预下载 AI 分包，平衡首屏与后续打开。

```js
export default defineAppConfig({
  pages: ['pages/home/index', 'pages/list/index', 'pages/ai/index', 'pages/me/index'],
  subPackages: [
    { root: 'packageExtra', pages: ['pages/export-web/index'] }
  ],
  preloadRule: {
    'pages/list/index': { network: 'wifi', packages: ['packageExtra'] }
  }
})
```

### 3. 主包过大怎么办

1. 图片/字体进 CDN，本地只留 tab 图标。  
2. 按业务拆分包（AI、导出、管理）。  
3. 扫依赖：误把大型 Markdown/编辑器打进主包。  
4. 分析工具看「主包体积构成」，迭代裁剪。  

**业务例子**：文档审评 tab（首页/文档/AI/我的）留主包；导出 H5、低频实验页可分包。面试强调「体积是上架硬约束，不是优化可选项」。

### 4. 信息架构与栈深控制

1. **列表→详情→子详情** 最多两层；更深用页内 Tab/锚点，或 redirect 掉中间页。  
2. **登录成功** 用 `reLaunch` 进首页，避免返回又回到登录页。  
3. **分享落地页** 可能是单页入口：`onLoad` 读 scene/query，再决定 `switchTab` 还是 `redirectTo`。  
4. **分包失败**：弱网提示「模块下载失败，请重试」；提供回主包的兜底入口。  
5. **体积治理节奏**：每迭代看主包占用；新增依赖先问「进哪个包」。  

面试官若追问「你们主包多少」：答「以当前微信限制为准，我们把 tab 与启动链路留主包，AI/导出进分包，并用 preloadRule 在 Wi‑Fi 预下载」，比报一个过时数字更稳。

## 可能追问

- independent subcontract？→ 独立分包可不依赖主包，适合中大型再拆。
- 分包异步化组件？→ 按需注入进一步降主包，注意基础库版本。
- H5 路由和小程序能完全同一套吗？→ Taro 可近似，tab/栈规则仍要条件处理。
