# 题 4：小程序应用/页面生命周期有哪些？和 Vue/React 怎么对应？

## 面试官可能怎么问

- App 与 Page 生命周期分别有哪些？
- onShow / onHide 和 mounted / unmounted 怎么区分？
- 从后台切回、tab 切换时数据该放哪？

## 口述结构（90 秒）

1. App：onLaunch / onShow / onHide —— 进程级
2. Page：onLoad / onShow / onReady / onHide / onUnload
3. onLoad 带 query 只来一次；onShow 每次可见都来
4. 拉数：首屏 onLoad+onShow 策略要分清；清理放 onUnload

## 参考答案

### 1. 生命周期表（先背结构）

**App**

| 钩子 | 何时 | 典型用途 |
| --- | --- | --- |
| onLaunch | 冷启动一次 | 读启动参数、初始化全局、静默登录 |
| onShow | 启动或从后台回前台 | 检查会话、刷新未读 |
| onHide | 进入后台 | 暂停音视频、停轮询 |

**Page**

| 钩子 | 何时 | 典型用途 |
| --- | --- | --- |
| onLoad(query) | 页面加载，参数在这 | 解析 id、注册一次的监听 |
| onShow | 每次显示（含返回、切 tab） | 刷新列表、同步全局态 |
| onReady | 首次渲染完成 | 算节点信息、依赖 DOM 尺寸 |
| onHide | 被遮罩/切走 | 停定时器、暂停播放 |
| onUnload | 卸载出栈 | 取消请求、清事件 |

Taro 函数组件常用 `useLoad` / `useDidShow` / `useReady` / `useDidHide` / `useUnload` 对应。

### 2. 和 Vue/React 的对应口径

- `onLoad` ≈ 路由进入时的「创建 + 读 params」（类似 setup + 首次 watch route）。  
- `onReady` ≈ `mounted` / `useEffect([])` 后能拿布局。  
- `onUnload` ≈ `unmounted` / effect cleanup。  
- **关键**：`onShow`/`onHide` 比 SPA 更频繁——从二级页 `navigateBack`、切 tab、从后台回来都会 `onShow`，**不等于**重新 `onLoad`。

```ts
useLoad((q) => { idRef.current = q.id })
useDidShow(() => { refreshIfStale() }) // 返回列表要刷新时
useUnload(() => { aborted = true })
```

### 3. 放数与清理的步骤

1. **只依赖路由参数的初始化** → `onLoad`。  
2. **每次露出都要最新**（列表未读、AI 会话状态）→ `onShow`，并做 stale 判断防抖。  
3. **读 DOM/Canvas** → `onReady` 或 `nextTick` 等价。  
4. **定时器/WS** → `onHide` 暂停，`onShow` 恢复；`onUnload` 彻底拆掉。  
5. **tab 页**很少 `onUnload`，状态易常驻——更要在 `onHide` 停副作用。

**业务例子**：文档列表 `onShow` 按筛选条件轻量刷新；AI 页 `onHide` 停止假打字机定时器，避免后台仍 setData。

## 可能追问

- onLoad 会不会在返回时再走？→ 页面还在栈里时不会；redirectTo/reLaunch 另说。
- 组件 lifetimes？→ attached/ready/detached，和页面钩子分层记。
- 和 keep-alive 类比？→ tab 页更像被缓存的实例，hide/show 而非销毁。
