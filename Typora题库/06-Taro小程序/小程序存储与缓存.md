# 题：小程序 Storage 和缓存策略？

## 面试官可能怎么问

- Storage 限制？
- 和内存状态怎么分工？
- 清缓存时机？

## 口述结构（90 秒）

1. `wx.setStorage` 持久化，有大小上限
2. 内存放运行态；持久放 token、草稿、用户偏好
3. 大文件用文件系统；别塞巨型 JSON
4. 版本升级做 migration / 清 key

## 参考答案

对话草稿存 Storage；消息列表太大只存最近 N 条或走服务端分页。敏感信息评估加密与过期。

## 可能追问

- 同步 vs 异步 API？→ 启动路径少用同步，防卡。
- 和 Vuex/Pinia？→ Taro 里状态库 + Storage 持久化插件。
