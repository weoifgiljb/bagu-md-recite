# 题：微信小程序双线程架构是什么？和 H5 差在哪？

## 面试官可能怎么问

- 逻辑层和渲染层怎么通信？
- 为什么不能直接操 DOM？
- setData 为什么是性能关键？

## 口述结构（90 秒）

1. 渲染层（WebView）+ 逻辑层（JSCore/V8），隔离
2. 两边经原生桥通信；不能像 H5 直接 DOM
3. 更新 UI 靠 `setData` 把数据打到渲染层
4. Taro/React 最后也要落到这套机制

## 参考答案

安全与性能：逻辑层没 DOM，页面结构用 WXML 描述。频繁、大数据 `setData` 会卡。

**业务例子**
AI 流式输出：节流合并 setData，只更新最后一条 message 字段，避免整列表序列化。

## 可能追问

- Skyline 渲染？→ 新渲染引擎，性能更好，兼容有门槛。
- 多 WebView？→ 多页多 WebView，内存要注意。
