# 题 16：实操——在火焰图 Bottom-Up 里按 Self 找出热点函数

## 面试官可能怎么问

- Self Time 和 Total Time 你优化哪个？
- Bottom-Up 和 Call Tree 各适合什么？
- 热点在 `vendor` 里怎么办？

## 口述结构（90 秒）

1. 先框选卡顿区间，避免整段噪声
2. Bottom-Up 按 Self 排序看 Top3
3. Call Tree 还原怎么调进来的
4. 业务代码优先改；第三方则换用法或懒加载

## 参考答案

### 操作步骤（照着点）

1. 按题 10 录一段 5 秒卡顿并 **Stop**。
2. 时间轴 **框选** 卡顿最重的 0.5～2 秒。
3. 下方面板点 **Bottom-Up**（不要停在只看火焰图彩色块）。
4. 点击 **Self Time** 列标题，让最大 Self 在最上。
5. 写下 Top3：函数名、Self、所属文件（业务 / 框架 / 库）。
6. 展开某一行左侧三角，看「谁调用了我」（parents）。
7. 再切到 **Call Tree**，从根往下对照同一区间，确认调用路径（例如点击 → dispatch → 大 list map）。
8. 决策：
   - Self 高在 **业务文件**：拆计算、虚表、memo、减 JSON 解析。
   - Self 高在 **框架 render**：减渲染次数与节点数量。
   - Self 高在 **某库**：是否不该同步用、能否 debounce、动态 import。
9. 改完用 **同一操作** 再录，对比 Top3 Self 是否下降（用数据说话）。

### 30 秒口诀（面试可背）

「框选 → Bottom-Up 看 Self → Call Tree 看路径 → 改业务热点 → 再录对比。」

## 可能追问

- Total 很大但 Self 很小？→ 时间花在子调用，继续往下钻叶子。
- 没有 source map？→ 用预发 map，或靠组件名 + 操作时机定位。
