# 题 11：实操——样式写了不生效，查出是谁覆盖的

## 面试官可能怎么问

- 类名挂上了但颜色不对，你怎么查？
- 划线的属性是什么意思？
- Computed 和 Styles 差在哪？

## 口述结构（90 秒）

1. Ctrl+Shift+C 选中真正的节点（防选错包装层）
2. Styles 看划线与来源文件
3. Computed 看最终值
4. :hov 强制 hover；必要时提高特异性或改结构

## 参考答案

### 操作步骤（照着点）

1. **Ctrl+Shift+C**，点页面上「看起来不对」的那个字/按钮。
2. 看 Elements 里高亮的是不是你以为的那个节点（组件库常有多一层 `span`/`div`）。
3. 右侧 **Styles** 面板从上往下扫：
   - 你的规则在不在列表里？不在 = 选择器没匹配上或文件没加载。
   - 属性被 **划掉** = 被别的规则盖了；看盖它的那条的选择器与文件行号。
4. 点划线旁/生效规则旁的 **文件名:行号**，跳到 Sources 确认是全局样式、UI 库还是 scoped CSS。
5. 打开 **Computed**，搜 `color` / `display` / `width`：看最终值，点小箭头看是哪条规则胜出。
6. 若只在 hover 才错：Styles 上点 **:hov**，勾选 `:hover`，再看规则。
7. 临时验证：在 `element.style` 里写 `color: red !important`：
   - 立刻变 → 问题是优先级/加载，不是「浏览器坏了」。
   - 不变 → 可能选错节点，或被更奇怪的东西盖（如伪元素、canvas）。
8. 修法方向（口述即可）：更具体的选择器、调整样式顺序、避免滥用 `!important`、检查 CSS Modules 类名是否绑错。

### 额外 30 秒：盒模型坑

Computed 下方盒模型图：若内容区比预期窄，查 `box-sizing`、padding 是否算进 width。

## 可能追问

- 为什么 Vue scoped 还被全局盖？→ 全局用了更高特异性或 `!important`，或属性打在子组件根上需 `:deep()`。
- 伪元素 `::before` 怎么查？→ Elements 里展开节点看 `::before`，再看 Styles。
