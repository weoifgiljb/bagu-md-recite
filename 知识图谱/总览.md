# 八股知识图谱 · 怎么用

记不住不是因为题太少，而是**概念没有挂在关系网上**。这张图谱把题库收成：

**主题域 → 高频概念 → 题库卡片**

## 打开方式

1. 进入本目录 `知识图谱/`
2. 先生成/刷新数据（挂接题库路径）：

```bash
python build_graph.py
```

3. 启动一个静态服务（推荐，避免浏览器拦截 `fetch`）：

```bash
python -m http.server 8766
```

4. 浏览器打开：<http://127.0.0.1:8766/>

也可在背诵本之外单独收藏这个地址。

## 怎么背（建议）

1. **先点左侧「记忆闭环」**（浏览器一圈 / Vue 响应式一圈 / AI 对话一圈…）——每天只走 1 个闭环。
2. 看概念之间的边：`先掌握` / `相关` / `对比` ——面试追问通常顺着这些边出来。
3. 右侧「题库卡片」路径用 Typora 打开原题细背。
4. 需要时勾选「显示题目叶子」，但不建议一上来就开（会花）。

## 和背诵本的关系

| 工具 | 作用 |
|------|------|
| 背诵本 | 单题过背、掌握度 |
| 知识图谱 | 看结构、串追问、找薄弱域 |
| Typora题库 | 改内容的源头 |

改完题库后重新跑一次 `python build_graph.py` 即可更新挂接。

## 文件

- `graph.base.json`：人工整理的域/概念/关系骨架
- `graph.json`：骨架 + 自动挂接的题卡
- `index.html`：可视化
- `build_graph.py`：刷新挂接
